# PROJECT COLDBORE

2–5 player tactical first-person shooter & armored tank arena built with **Three.js**, **Google Firebase Auth & Realtime Database**, and **Venge.io-style smart input detection** for **iPad (30–60 FPS)** and **Desktop**.

## Key Features
- **3 Distinct Arenas & Custom Shaders**:
  - **Sunlit Cargo Harbor**: Golden-hour coastal container port with animated GLSL sunset ocean water, towering harbor cranes, docked freighter ship, port terminal buildings, and multi-colored shipping containers.
  - **Desert Dunes & Outpost**: Sculpted rolling desert sand hills, enterable sandstone compound houses & forts, swaying palm trees, and cacti.
  - **Alpine Snow Peaks**: Sculpted snowy mountain terrain, snow-roofed alpine cabins, rotating radar bunkers, snow-capped pine trees, and drifting snowfall.
- **Tactical Arsenal & Tanks**:
  - `M4A1 Tactical`, `M1014 Shotgun`, `AWP Tactical` (accurate crosshair-aligned sniper + scope), `USP-S Sidearm`, and `HE-67 Frag Grenades`.
  - **2 Neutral Drivable Tanks**: Enter/exit with `E` (or tap **DRIVE** / **EXIT**), chase camera, `120mm` main cannon with recoil, and coaxial MG.
- **Smart Input Detection**:
  - **Desktop**: Mouse + `WASD` (touch UI hidden).
  - **iPad Keyboard + Touch**: Left virtual thumbstick hides when using hardware keyboard; move with `WASD` and aim/shoot on display.
  - **iPad Touch-Only**: Floating left movement joystick + drag-to-aim while holding **FIRE**.
- **2–5 Player Multiplayer & Configurable AI Practice**:
  - Preconfigured for `project-coldbore` with Google Sign-In, room codes, live RTT latency (`ms`) + FPS readout, and Solo Practice (`Casual`, `Tactical`, `Veteran` AI).
